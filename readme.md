# AI Cargo Scanner & Safety Classifier 

ระบบ AI ช่วยตรวจจับ คัดกรองวัตถุอันตราย และจัดหมวดหมู่พัสดุในคลังสินค้าอัตโนมัติผ่านภาพถ่ายและข้อความ 

## ฟีเจอร์จาก Lab ที่นำมาใช้
1. **System Instructions:** กำหนดพฤติกรรม AI ให้เข้มงวดและเชี่ยวชาญด้านกฎหมายวัตถุอันตรายสากล
2. **Structured Output:** ล็อกโครงสร้างผลลัพธ์เป็น JSON Schema 100% เพื่อเชื่อมต่อกับระบบหลังบ้านของคลังสินค้า
3. **Multimodality:** ส่งรูปถ่ายสินค้าหรือป้ายเตือนภัยบนกล่องให้ AI ตรวจสอบทางกายภาพ
4. **Function Calling:** เรียกเครื่องมือเช็คกฎระเบียบการขนส่ง (Regulations) เพื่อดูข้อห้ามทางกฎหมาย
5. **Streaming (โจทย์เสริม):** ใช้การตอบกลับแบบ Streaming เพื่อให้เจ้าหน้าที่หน้างานเห็นผลลัพธ์การสแกนทันทีโดยไม่ต้องรอโหลดนาน

## การตั้งค่า Temperature และเหตุผล
- **Temperature: 0.1**
- **เหตุผล:** งานนี้เกี่ยวข้องกับความปลอดภัยในคลังสินค้าและข้อบังคับทางกฎหมาย จึงต้องการความถูกต้อง แม่นยำ ไม่ต้องการความไร้ตรรกะหรือความคิดสร้างสรรค์ที่อาจทำให้เกิดความเสี่ยงต่อชีวิตและทรัพย์สิน

## ส่วนที่ใช้ AI ในระบบ
- ดูภาพถ่ายเพื่ออ่านป้ายเตือนภัย หรือวิเคราะห์ประเภทวัตถุ
- ประมวลผลร่วมกับ Tool เพื่อตัดสินใจว่าพัสดุชิ้นนี้สามารถขนส่งได้หรือไม่
- จัดรูปแบบข้อมูลให้ออกมาเป็นโครงสร้าง JSON ตามที่กำหนดไว้

## ตัวอย่าง Input / Output
### Input
- **Image:** ภาพขวดสเปรย์แอลกอฮอล์หรือถังสารเคมี
- Text Input: รองรับการกรอกข้อมูลสดจากผู้ใช้งานหน้างานผ่านหน้าจอคอนโซล (Dynamic User Input) ทั้งช่องวิธีขนส่ง (Shipping Method) และบันทึกเพิ่มเติมจากเจ้าหน้าที่ (Operator Notes)

### Output (JSON)

{
  "item_name": "สเปรย์แอลกอฮอล์แรงดันสูง (Aerosol)",
